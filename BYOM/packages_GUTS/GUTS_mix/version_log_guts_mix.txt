Version log GUTS_mix package for BYOM

===========================================================================
What is it?

Extension of the reduced GUTS models SD and IT for dealing with binary mixtures. The model extension is presented and discussed in Bart et al (2021). This package requires BYOM v.6.0 beta 8 or newer! See the 'about' text file in this directory for more information.
===========================================================================
