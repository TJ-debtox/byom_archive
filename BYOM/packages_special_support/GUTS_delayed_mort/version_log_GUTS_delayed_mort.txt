Version log GUTS_delayed_mort package for BYOM

===========================================================================
What is it?

This package contains the files needed to reproduce the analyses in my paper on delayed mortality (Jager, 2024). See the 'Notes_...' text file in this directory for more information.

Jager T (2024). Identifying and predicting delayed mortality with toxicokinetic-toxicodynamic models. Environ Toxicol Chem 43(5):1030-1035. https://doi.org/10.1002/etc.5833 (accepted version and SI can be found with the entry on https://www.debtox.info/papers_survival.html).
===========================================================================
